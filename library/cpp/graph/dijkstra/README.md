# ダイクストラ法

辺の重みが 0 以上の有向グラフで、始点から各頂点への最短距離を求める。距離が小さい頂点から順に確定し、その頂点から伸びる辺で隣を更新する。

負の辺があると、確定した距離が後から短くなり、この手順は正しくない。負の辺があるときはベルマンフォード法など別の方法を使う。

## include

```cpp
#include "library/cpp/graph/dijkstra/dijkstra.hpp"
```

`template.hpp` は、このヘッダが読み込む。

## API

```cpp
struct Dijkstra {
  vi dist;
  vi parent;
};

Dijkstra dijkstra(const vc<vc<pi>> &g, int s);
```

- `g[v]` は、頂点 `v` から出る辺の配列。要素は `{行き先, 重み}`。頂点番号は `0` 以上 `g.size()` 未満。
- 重みは `0` 以上の `ll`。負の重みは渡さない。
- `s` は始点。`dist[v]` は `s` から `v` への最短距離。届かなければ `INF`（`1 << 60`）。
- `parent[v]` は、その最短路で `v` の直前にいる頂点。始点と、届かない頂点は `-1`。
- 同じ行き先へ複数の辺があってもよい。最短の更新に使った辺の重みは、`dist[v] - dist[parent[v]]` と一致する辺を `g[parent[v]]` から探せばよい。

## 計算量と制約

頂点数 `N`、辺数 `M` として `O((N + M) log N)`。ヒープに同じ頂点が複数回入ることがある。`N` と `M` がそれぞれ `5 * 10^5` 程度までを想定する。距離の和が `INF` 以上になると、届かない頂点と区別できない。重み `w` の合計が `10^18` に近いグラフでは、`INF` を問題に合わせて大きくする。

## 使用例

頂点数 `N`、辺数 `M`、始点 `S`、終点 `T` を読む。辺は 1 始まりの `u v w`（`u` から `v` へ重み `w`）。`T` への距離と、直前の頂点（1 始まり。届かなければ `-1`）を出す。

入力形式:

```text
N M S T
u_1 v_1 w_1
...
u_M v_M w_M
```

```cpp
#include "library/cpp/graph/dijkstra/dijkstra.hpp"

int main() {
  int N, M, S, T;
  cin >> N >> M >> S >> T;
  S--;
  T--;
  vc<vc<pi>> G(N);
  for (int i = 0; i < M; i++) {
    int u, v;
    ll w;
    cin >> u >> v >> w;
    u--;
    v--;
    G[u].push_back({v, w});
  }
  auto res = dijkstra(G, S);
  print(res.dist[T]);
  if (res.parent[T] < 0) {
    print(-1);
  } else {
    print(res.parent[T] + 1);
  }
  return 0;
}
```

入力例:

```text
3 2 1 3
1 2 2
2 3 3
```

出力例:

```text
5
2
```

## こういう問題なら使う

「一方通行の道があり、移動時間は 0 以上」「始点から各町への最短時間」「最短路の距離だけでなく、経路も復元する」。辺の重みに負がある、または「スコアを最大化する」形で負辺に直す問題には使わない。

確認できた例題:

- [ABC 035 D - トレジャーハント](https://atcoder.jp/contests/abc035/tasks/abc035_d)。町と一方通行の道があり、移動時間 `c_i` は正。制限時間内に出発点へ戻る。ページを取得し、重みが正の有向グラフで最短路を使う問題文であることを確認した。往復なので、逆向きの辺についても最短路を求める。

## 注意点

- 頂点番号が問題文で 1 始まりなら、辺を入れる前に `1` を引く。
- 無向辺は、両方の向きに同じ重みの辺を入れる。
- `dist[v] == INF` の頂点から経路を辿らない。`parent` は `-1` のままである。
- 重みが `int` でも、距離の和は `ll` で持つ。この実装の `dist` は `vi`（`vector<ll>`）である。
- ヒープの要素は `{距離, 頂点}` である。順番を逆にすると、頂点番号で先に比較する。

## 関連

重みが 0 と 1 だけなら [01-BFS](../bfs01/README.md) の方が定数が小さい。負辺がある最短路は、この関数では扱わない。AtCoder Library にダイクストラ法はない。
