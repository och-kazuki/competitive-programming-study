# いもす法

「区間 `[l, r)` に `v` を足す」をたくさん行ったあと、各点の最終的な値をまとめて作る。1回の加算は端の2箇所（二次元なら長方形の4隅）だけを更新し、最後に累積和を1回取る。

各点をループで更新すると、区間の長さの分だけ時間がかかる。差分配列なら、区間の始点に `+v`、終点に `-v` を書いておき、左から足し込めば同じ結果になる。

## include

```cpp
#include "library/cpp/range/imos/imos.hpp"
```

`template.hpp` は、このヘッダが読み込む。

## API

```cpp
struct Imos1D {
  explicit Imos1D(int n);
  void add(int l, int r, ll v);
  vi build() const;
};

struct Imos2D {
  Imos2D(int h, int w);
  void add(int y1, int x1, int y2, int x2, ll v);
  vvc<ll> build() const;
};
```

- 添字は 0 始まり。区間も矩形も半開である。
- 1 次元の `add(L, R, X)` は、位置 `L, L+1, ..., R-1` に `X` を足す。位置 `R` は含まない。
- 2 次元の `add(U, L, D, R, X)` は、行 `U` から `D - 1`、列 `L` から `R - 1` に `X` を足す。行 `D` と列 `R` は含まない。

```text
        列 L          列 R
行 U    +---------------+
        |  X を加える   |
行 D    +---------------+
```

- 問題文が 1 始まりの閉区間 `[A, B]` なら、`add(A - 1, B, X)`。二次元で行 `A` から `B`、列 `C` から `D`（両端を含む）なら、`add(A - 1, C - 1, B, D, X)`。
- 0 始まりの半開区間として読んだ `U, D, L, R` は、そのまま `add(U, L, D, R, X)` に渡す。
- `L == R` や `U == D` の空範囲は、どの点も変えない。
- `build` は各点の値を返す。1 次元は長さ `N`、2 次元は `H` 行 `W` 列。
- `0 <= L <= R <= N`、`0 <= U <= D <= H`、`0 <= L <= R <= W` であること。

## 計算量と制約

1 次元は加算 `Q` 回が `O(Q)`、構築が `O(N)`。2 次元は加算 `O(Q)`、構築 `O(HW)`。`N` や `HW` が `10^7` 前後までなら配列を確保できることが多い。値は `ll`。

## 使用例

`H` 行 `W` 列に、1 始まりの閉矩形（行 `U` から `D`、列 `L` から `R`）へ `X` を足し、各マスの値を出す。

入力形式:

```text
H W Q
U_1 D_1 L_1 R_1 X_1
...
U_Q D_Q L_Q R_Q X_Q
```

```cpp
#include "library/cpp/range/imos/imos.hpp"

int main() {
  int H, W, Q;
  cin >> H >> W >> Q;
  Imos2D im(H, W);
  while (Q--) {
    int U, D, L, R;
    ll X;
    cin >> U >> D >> L >> R >> X;
    im.add(U - 1, L - 1, D, R, X);
  }
  print(im.build());
  return 0;
}
```

入力例:

```text
2 3 1
1 2 1 2 5
```

出力例:

```text
5 5 0
5 5 0
```

## こういう問題なら使う

「区間に一斉に足す操作のあと、各位置の値や最大値を求める」「長方形を何枚も重ね、1枚以上で覆われたマスを数える」。操作の順序が結果に影響せず、最後の状態だけが欲しいときに向く。途中で消える要素を追う問題には向かない。

確認できた例題:

- [ABC 014 C - AtColor](https://atcoder.jp/contests/abc014/tasks/abc014_3)。閉区間 `[a, b]` の色を買う人数を重ね、最大を求める。ページを取得し、区間の重なりの最大を求める問題文であることを確認した。添字は 0 から `1000000` までを含むので、半開にするなら `add(a, b + 1, 1)` で、配列長は `1000001`。
- [ABC 035 C - オセロ](https://atcoder.jp/contests/abc035/tasks/abc035_c)。閉区間の駒を裏返す。ページを取得し、区間の反転回数の偶奇を求める問題文であることを確認した。
- [ABC 318 B - Overlapping sheets](https://atcoder.jp/contests/abc318/tasks/abc318_b)。軸に平行な長方形が1枚以上覆う面積。ページを取得し、長方形の重なりの面積を求める問題文であることを確認した。問題の範囲は `A ≤ x ≤ B` のように両端を含む。このライブラリの半開区間へ直すときは、上端を `B + 1`、`D + 1` にする。

## 注意点

- 1 始まりの閉区間 `[A, B]` は `add(A - 1, B, X)`。`B` のまま終点にすると、位置 `B`（1 始まり）が含まれない。
- 右端が配列の最後の要素のとき、差分は長さ `N + 1` の末尾に書く。この構造体は最初からその長さを確保している。
- 加算 1 回の値が `X`、回数が `Q` のとき、1 点の合計は最大約 `QX`。`Q` が `10^5`、`X` が `10^9` なら `10^14` なので `ll` が要る。
- 座標が `10^9` のまま二次元配列にはできない。先に [座標圧縮](../compress/README.md) してから `H` と `W` を決める。

## 関連

値が先に決まっていて範囲の和を聞くのは [二次元累積和](../cumsum2d/README.md)。いもす法は、加算が先で各点の値を後から復元する。AtCoder Library には、この形のいもす法はない。
