# 一次元累積和

長さ `N` の数列 `A` について、「区間の和はいくつ？」を何度も聞くときに使う。先に先頭からの和を表 `S` にしておけば、1回の質問は引き算1つで終わる。

`S[0] = 0`、`S[i + 1] = S[i] + A[i]` とする。`S[i]` は `A[0] + ... + A[i - 1]` である。0 始まりの半開区間 `[L, R)` の和は `S[R] - S[L]` になる。

```text
A:  A[0] A[1] A[2] ... A[N-1]
S:  0    S[1] S[2] S[3] ... S[N]

区間 [L, R) の和 = S[R] - S[L]
```

## include

```cpp
#include "library/cpp/range/cumsum/cumsum.hpp"
```

`template.hpp` は、このヘッダが読み込む。

## API

```cpp
template <class T, class A> vc<T> cumsum(const A &a);
```

- `A` は長さ `N` の数列。添字は 0 始まり。
- 返り値 `S` の長さは `N + 1`。`S[0]` は `0`。`S[i]` は `A[0] + ... + A[i - 1]`。
- 半開区間 `[L, R)` の和は `S[R] - S[L]`。`L == R` なら `0`。
- 問題文が 1 始まりの閉区間 `[L, R]`（両端を含む）なら、`S[R] - S[L - 1]`。
- `T` は和を持つ型。`A` の要素が `int` でも、和を `ll` で持つなら `cumsum<ll>(A)` とする。

## 計算量と制約

構築は `O(N)`、質問 `Q` 回は `O(Q)`。`N` は、長さ `N + 1` の `vc<T>` がメモリに載る範囲。

## 使用例

長さ `N` の数列 `A` を読み、質問ごとに 1 始まりの閉区間 `[L, R]` の和を出す。

入力形式:

```text
N Q
A_1 A_2 ... A_N
L_1 R_1
...
L_Q R_Q
```

```cpp
#include "library/cpp/range/cumsum/cumsum.hpp"

int main() {
  int N, Q;
  cin >> N >> Q;
  vc<ll> A(N);
  for (int i = 0; i < N; i++) {
    cin >> A[i];
  }
  vc<ll> S = cumsum<ll>(A);
  while (Q--) {
    int L, R;
    cin >> L >> R;
    print(S[R] - S[L - 1]);
  }
  return 0;
}
```

入力例:

```text
4 2
1 2 3 4
2 4
1 1
```

出力例:

```text
9
1
```

## こういう問題なら使う

「数列の区間の合計を何度も求める」「各位置までの和を前計算して、条件を満たす範囲を探す」。1回だけならループで足りる。質問回数や、試す区間の個数が多いときに前計算する。文字の出現回数も、0 と 1 の列にすれば同じ形になる。

確認できた例題:

- [ABC 122 C - GeT AC](https://atcoder.jp/contests/abc122/tasks/abc122_c)。長さ `N` の文字列について、区間 `[l, r]` に `AC` が何回現れるかを `Q` 回聞く。ページを取得し、区間内の `AC` の個数を答える問題文であることを確認した。`AC` が始まる位置を 1、それ以外を 0 にした列の累積和で求まる。
- [ABC 098 C - Attention](https://atcoder.jp/contests/abc098/tasks/arc098_a)。`E` と `W` が並ぶ列で、リーダーを1人選んだときに向きを変える人数の最小を求める。ページを取得し、その問題文であることを確認した。西から `i` 番目までにある `W` の個数は、0 と 1 の列の累積和で求まる。

## 注意点

- 半開区間である。1 始まりの閉区間 `[L, R]` は `S[R] - S[L - 1]`。0 始まりの半開区間 `[L, R)` は `S[R] - S[L]`。
- `L` が 1 始まりのまま `S[L]` を引くと、区間の左端が1つずれる。
- 空の数列の `S` は長さ 1 で、中身は `0` だけである。
- 和が約 `9.2 * 10^18` を超えると `ll` が溢れる。`int` の列でも `cumsum<ll>` にする。

## 関連

二次元に広げたものは [二次元累積和](../cumsum2d/README.md)。区間への加算が先で、各点の値を後から見るのは [いもす法](../imos/README.md)。AtCoder Library には、この形の一次元累積和はない。
