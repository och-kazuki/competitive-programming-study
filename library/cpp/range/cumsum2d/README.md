# 二次元累積和

長方形に並んだ数について、「この範囲の合計はいくつ？」を何度も聞くときに使う。先に左上からの累積を表にしておけば、1回の質問は引き算4つで終わる。

考え方は1次元の累積和と同じである。マス `(y, x)` までの長方形（`y` は行、`x` は列。どちらも 0 始まりで、右と下は含まない）の和を `s[y+1][x+1]` に置く。知りたい範囲は、大きい長方形から左側と上側を引き、二重に引いた左上を足し戻す。

## include

```cpp
#include "library/cpp/range/cumsum2d/cumsum2d.hpp"
```

`template.hpp` は、このヘッダが読み込む。

## API

```cpp
struct Cumsum2D {
  int h, w;
  vvc<ll> s;
  explicit Cumsum2D(const vvc<ll> &a);
  ll sum(int y1, int x1, int y2, int x2) const;
};
```

- `A` は `H` 行 `W` 列。各行の長さは `W` で揃っていること。空なら `H = 0`。
- 添字は 0 始まり。`sum(U, L, D, R)` は半開矩形で、行 `U` から `D - 1` まで、列 `L` から `R - 1` まで。行 `D` と列 `R` は含まない。

```text
        列 L          列 R
行 U    +---------------+
        | この範囲の和  |
行 D    +---------------+
```

- 問題文が 1 始まりの閉区間で、行 `A` から `B`、列 `C` から `D`（両端を含む）なら、`sum(A - 1, C - 1, B, D)` と渡す。
- 返り値はその範囲の和。`U == D` または `L == R` なら `0`。
- `s[y][x]` は、行 `0` から `y - 1`、列 `0` から `x - 1` までの和。`s` の大きさは `(H + 1)` 行 `(W + 1)` 列。

## 計算量と制約

構築は `O(HW)`、質問 `Q` 回は `O(Q)`。`H` と `W` は、`ll` の表がメモリに載る範囲。範囲の和は `ll`。

## 使用例

`H` 行 `W` 列の表 `A` を読み、質問ごとに 1 始まりの閉区間（行 `U` から `D`、列 `L` から `R`）の和を出す。

入力形式:

```text
H W
A_{1,1} ... A_{1,W}
...
A_{H,1} ... A_{H,W}
Q
U_1 D_1 L_1 R_1
...
U_Q D_Q L_Q R_Q
```

```cpp
#include "library/cpp/range/cumsum2d/cumsum2d.hpp"

int main() {
  int H, W;
  cin >> H >> W;
  vvc<ll> A(H, vi(W));
  for (int y = 0; y < H; y++) {
    for (int x = 0; x < W; x++) {
      cin >> A[y][x];
    }
  }
  Cumsum2D cs(A);
  int Q;
  cin >> Q;
  while (Q--) {
    int U, D, L, R;
    cin >> U >> D >> L >> R;
    print(cs.sum(U - 1, L - 1, D, R));
  }
  return 0;
}
```

入力例:

```text
2 3
1 2 3
4 5 6
1
1 2 2 3
```

出力例:

```text
16
```

## こういう問題なら使う

「格子上の長方形範囲の合計を、何度も求める」「すべての長方形のうち、面積やマス数が条件を満たすものの最大値を求める」。1回だけなら二重ループで足りる。質問回数や、試す長方形の個数が多いときに前計算する。

確認できた例題:

- [ABC 005 D - おいしいたこ焼きの焼き方](https://atcoder.jp/contests/abc005/tasks/abc005_4)。`N×N` の美味しさから、面積が `P` 以下の長方形の合計の最大を店員ごとに求める。ページを取得し、長方形の合計を求める問題文であることを確認した。

## 注意点

- 半開区間である。1 始まりの閉区間（行 `A` から `B`、列 `C` から `D`）は `sum(A - 1, C - 1, B, D)`。0 始まりの半開区間なら、読んだ `U, D, L, R` をそのまま `sum(U, L, D, R)` に渡す。
- 行の長さが揃っていない表は、`w` を先頭行の長さとして読む。短い行は範囲外参照になる。
- 要素や範囲の和が約 `9.2 * 10^18` を超えると `ll` が溢れる。

## 関連

同じフォルダの [いもす法](../imos/README.md) は、長方形への加算が先に来て、最後に各マスの値を見る向きである。累積和は、表が先に決まっていて範囲の和を聞く向きである。1次元の累積和は `template.hpp` の `cumsum` がある。
