# upsolve

コンテスト後に、問題ごとに1ファイル残します。ファイル名は `コンテスト-問題.md` にします。例: `abc400-a.md`。

次の見出しを使います。空欄のままにせず、無関係なら「なし」と書きます。

```markdown
# コンテスト 問題名

## 問題リンク

## 要点

その問題で新しく使えるようになったことを、短く書きます。

## 解法

方針と、実装で大事な点を書きます。コード全体の写しは不要です。

## ハマった点

WA や TLE の原因、境界、実装ミスを書きます。

## 関連ライブラリ

`library/` や `notes/algorithms/` への相対パスを書きます。無ければ「なし」。
```

記入例は [example.md](example.md) です。これは説明用のサンプルで、実際のコンテスト記録ではありません。
