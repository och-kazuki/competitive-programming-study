# 記入例: ABC 086 A - Product

これはノートの書き方を示すサンプルです。コンテスト中の記録ではありません。

## 問題リンク

<https://atcoder.jp/contests/abc086/tasks/abc086_a>

## 要点

二つの整数の積が偶数か奇数かだけを見ればよい。積そのものを大きな整数として扱う必要はない。

## 解法

両方が奇数のときだけ積は奇数になる。それ以外は偶数。

1. `a` と `b` を読む。
2. `a % 2 == 1 && b % 2 == 1` なら `Odd`、そうでなければ `Even` を出力する。

## ハマった点

- 出力は `Yes` / `No` ではなく `Even` / `Odd`。テンプレートの `YES` / `NO` をそのまま使うと WA になる。
- 偶奇は和ではなく積で決まる。片方が偶数なら積は偶数。

## 関連ライブラリ

なし。偶奇の判定だけなので `library/cpp/binary_search.hpp` は使わない。
